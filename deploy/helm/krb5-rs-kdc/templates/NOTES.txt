krb5-rs KDC for realm {{ .Values.realm }}: one primary and {{ .Values.replicas.replicaCount }} replica(s).

1. Find the KDC address (Service "{{ include "krb5-rs-kdc.fullname" . }}-kdc", port {{ .Values.service.port }} UDP+TCP):
{{- if eq .Values.service.type "LoadBalancer" }}

     kubectl get svc {{ include "krb5-rs-kdc.fullname" . }}-kdc --namespace {{ .Release.Namespace }} -o jsonpath='{.status.loadBalancer.ingress[0].ip}{.status.loadBalancer.ingress[0].hostname}'
{{- else if eq .Values.service.type "NodePort" }}

     kubectl get svc {{ include "krb5-rs-kdc.fullname" . }}-kdc --namespace {{ .Release.Namespace }} -o wide
{{- else }}

     {{ include "krb5-rs-kdc.fullname" . }}-kdc.{{ .Release.Namespace }}.svc (ClusterIP, in-cluster only)
{{- end }}

2. Client krb5.conf:

     [libdefaults]
       default_realm = {{ .Values.realm }}
     [realms]
       {{ .Values.realm }} = {
         kdc = <address from step 1>:{{ .Values.service.port }}
       }

3. Administer the database. Writes go ONLY to the primary pod; replicas are read-only copies
   the primary pushes to every {{ .Values.propagation.interval }}s (MIT kprop to kpropd). Passwords are read from stdin (use -i):

     printf 'the-password\n' | kubectl exec -i --namespace {{ .Release.Namespace }} statefulset/{{ include "krb5-rs-kdc.fullname" . }}-primary -c kdc -- \
       krb5-rs-kdb --config /etc/krb5-rs/kdc.conf --krb5-config /etc/krb5-rs/krb5.conf --realm {{ .Values.realm }} addprinc alice

   Other commands: delprinc, cpw, modprinc, getprinc, listprincs, ktadd -k PATH NAME.
{{- if .Values.kadmin.enabled }}

4. Remote administration: MIT kadmin and kpasswd reach the primary's krb5-rs-kadmind through
   Service "{{ include "krb5-rs-kdc.fullname" . }}-kadmin" (kadmin {{ .Values.kadmin.service.port }}/TCP, kpasswd {{ .Values.kadmin.service.kpasswdPort }} UDP+TCP). Add to the
   client's realm section:

         admin_server = <kadmin Service address>:{{ .Values.kadmin.service.port }}
         kpasswd_server = <kadmin Service address>:{{ .Values.kadmin.service.kpasswdPort }}

   Permissions come from kadmin.acl (MIT kadm5.acl lines); create the admin principals with
   addprinc above, then for example:

     kadmin -p admin/admin -q listprincs
{{- end }}

What HA means here: the replicas keep answering AS and TGS requests while the primary is down
or restarting, using the last database they received. Administrative changes wait for the
primary (as with MIT kprop) and reach the replicas within one propagation interval after it returns.
The "master-password" and "kprop-password" (host/ kprop principals) keys live in Secret "{{ include "krb5-rs-kdc.secretName" . }}".

krb5-rs KDC for realm {{ .Values.realm }}: {{ .Values.kdcs.replicaCount }} CockroachDB-backed KDC pod(s).

The idempotent pre-install/pre-upgrade bootstrap hook migrates the database and creates the
realm when enabled.
{{ if .Values.kdcs.persistence.enabled }}
Each KDC pod keeps its Turso replica on a PVC. Heartbeats identify the {{ .Values.cockroach.region }} region.
{{ else }}
Each KDC pod keeps its Turso replica in a pod-local emptyDir; a restart takes a fresh snapshot.
Heartbeats identify the {{ .Values.cockroach.region }} region.
{{ end }}

Client krb5.conf:

     [libdefaults]
       default_realm = {{ .Values.realm }}
       dns_lookup_kdc = false
     [realms]
       {{ .Values.realm }} = {
         kdc = {{ include "krb5-rs-kdc.fullname" . }}-kdc.{{ .Release.Namespace }}.svc:{{ .Values.service.port }}
       }

Administer with a temporary pod using the kdc_admin certificate, the master-password Secret,
and the chart configuration. Set `cockroach.admin.url` and `cockroach.admin.tlsSecret` to render
the admin profile and certificate mount.
{{- if and .Values.cockroach.admin.url .Values.cockroach.admin.tlsSecret }}

Add a principal:

     kubectl run {{ include "krb5-rs-kdc.fullname" . }}-kdb --namespace {{ .Release.Namespace }} --rm -i --attach --restart=Never --image={{ include "krb5-rs-kdc.image" . | quote }} --overrides='{"apiVersion":"v1","spec":{"securityContext":{{ toJson .Values.podSecurityContext }},"containers":[{"name":"{{ include "krb5-rs-kdc.fullname" . }}-kdb","image":"{{ include "krb5-rs-kdc.image" . }}","imagePullPolicy":"{{ .Values.image.pullPolicy }}","securityContext":{{ toJson .Values.securityContext }},"volumeMounts":[{"name":"config","mountPath":"/etc/krb5-rs","readOnly":true},{"name":"secrets","mountPath":"/secrets","readOnly":true},{"name":"crdb-admin","mountPath":"/crdb-admin","readOnly":true},{"name":"tmp","mountPath":"/tmp"}]}],"volumes":[{"name":"config","configMap":{"name":"{{ include "krb5-rs-kdc.fullname" . }}"}},{"name":"secrets","secret":{"secretName":"{{ include "krb5-rs-kdc.secretName" . }}","defaultMode":288}},{"name":"crdb-admin","secret":{"secretName":"{{ .Values.cockroach.admin.tlsSecret }}","defaultMode":288}},{"name":"tmp","emptyDir":{}}]}}' --override-type=strategic --command -- krb5-rs-kdb --config /etc/krb5-rs/admin-kdc.conf --krb5-config /etc/krb5-rs/krb5.conf --realm {{ .Values.realm }} --master-password-file /secrets/master-password addprinc alice
